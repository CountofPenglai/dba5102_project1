# 当前研究验证协议v3

当前H0及混合研究统一使用[validation_protocol_v3.json](../config/validation_protocol_v3.json)，时间为UTC、区间右端不含。该协议用于研究角色，不改写[preprocessing_v1.json](../config/preprocessing_v1.json)的历史存储分区。

| 项目 | 当前规则 |
|---|---|
| 训练起点 | 2026-04-01 00:00:00 |
| 滚动验证 | 2026-05-01 00:00:00至2026-07-31 17:11:48 |
| 更新节奏 | 自5月1日起连续每7日，不按月重置 |
| 更新时刻D可用样本 | 创建时间≥max(4月1日,D−30日)，创建时间<D，实际结算时间<D |
| 周内 | 参数冻结；报价时使用当时可用的合同、Base及已结束行情 |
| 标签反馈 | 验证订单结算后，可供下一次合法更新；不影响此前预测 |
| 尾部阈值 | 每月初只用4月以来已创建且已结算的历史，方向×期限q90，不足时按原规则回退 |
| 新官方验证 | 禁止读取，不用于选参、评分或补充训练 |
| 选参 | 经授权做固定候选粗/细网格；不得按月份事后拼赢家 |

实施位于`pp_models/h0_time_decay_study.py`中的`PROTOCOL`和`history_ids`，后续H0混合/小时研究复用。`h0_blend_fine_study`重放已验证周参数，仍逐周核对训练/查询样本和时间。7月1–2日延用6月26日参数，7月3日才更新，相关行为有回归测试。

`load_pool('test', ...)`在这些研究中加载历史存储分区的并集，再由v3限定角色；名称test不能解释为启用了未见官方测试。先前分区结束前尚未结算而被排除的记录仍不补回。评价还要求标签在验证结束前已结算，所有模型使用相同队列。

月等权RMSE为`√mean(月MSE)`，MAE为月MAE等权均值，同时报告全部订单合并误差。当前队列4,640单，月份分别726、1,373、2,541。RMSE为主，MAE监控，方向尾部和金额低估约束另外核查。

5–7月已用于多轮开发，7月不再是独立测试；原报告中的4–6月开发、7月压力复查仅描述对应历史实验。官方是否有真实标签反馈仍未知，当前周更协议不能直接外推到无标签场景。

旧`pp_models.rolling_protocol`/`validation_protocol_v2.json`保留原4–6月日更研究，通用`pp_models study-run`保留早期六月流程，不改其历史含义。当前应显式运行`pp_models.h0_*_study`，见[README](../README.md)。

# 报告模型与公共组件

当前只保留解释H0与Base有限混合研究路径所需的99个配置。Base保持官方提供值，所有模型共用[验证协议v3](validation_protocol_v3.md)、报价队列和评分。单项模块仅提供配方，唯一执行入口是`python -m pp_models`。

## H0两阶段核心

实现已独立为[pp_models/h0.py](../pp_models/h0.py)，不再依赖包含其他实验的通用模型类。

Call、Put分别估计正赔付概率p和正赔付金额系数s，输出`H0 = p × Base × s`。概率模型为L2逻辑回归，C=0.1、最多1,000轮、容差1e-9。输入为log(Base)、log(剩余期限)和方向价格位置：`(1−2×方向) × log(市场价/执行价) / max(60分钟波动 × sqrt(剩余小时), 1e-6)`，价格位置先截断至±5，历史标准化后特征截断至±3。

金额系数在该方向正赔付历史上拟合无截距最小二乘：`s = Σ(Base×赔付) / Σ(Base²)`。单类概率直接用历史比例；某方向没有历史时保守回退Base。模型接口只接受6项合同/行情字段，移除了原通用接口中的全零终值占位特征。目标仅用当时已结算赔付，提前终止信息不作报价输入。

## 保留的探索

| 配方 | 设置与研究意义 |
|---|---|
| 固定混合 | `预测 = α方向 × H0 + (1−α方向) × Base`；粗网格两个方向均0/25/50/75/100%，细网格Call25–65%、Put10–40%，步长5%；去重后86种，含Base/H0/50%混合 |
| 时间衰减 | 创建年龄半衰期7或14日，同时加权概率与金额；用于检验近期样本是否减少滞后 |
| 小时金额响应 | 概率固定H0；Call用上行、Put用下行60/240分钟波动；比较水平、水平＋速度、保守门控；ridge=100，连续项±10%、门控0至+10%，支持不足保留H0 |
| 状态回退与历史误差混合 | 波动水平、涨跌不平衡、趋势的分布偏离门控；另用已结算前向误差拟合强收缩混合比例；比较两者组合 |
| 动态网格比例 | 用14或30日已结算前向误差选择既定粗网格比例，样本不足回到Base，不使用事后月份最优值 |
| 公告倍率 | 共享阶段结构，方向差异强收缩；收缩1/10/100，总幅度±5%、方向±2%；共享至少30单/5事件/2个月，方向60单/8事件/3个月，否则回退1 |

上述13个额外配置与86个固定比例共99个。保留负结果是为了说明为何简单有限混合优于当前尝试过的动态增量；不代表它们都应部署。三档公告模型在共同30日窗均不满足支持条件，因此与Base相同。当前完整成绩及局限见[研究结果](reports/2026-10-15-report-unified-rerun.md)。

## 公共能力与依赖

| 模块 | 单一职责 |
|---|---|
| `pp_data` | 质量、特征白名单、平面数据存储与验证；不含旧日期分区接口 |
| `h0.py`、`validation.py` | H0拟合与参数序列化；统一历史、尾部上下文 |
| `metrics.py`、`resampling.py`、`fixed_blend_statistics.py` | 误差和现金口径、成对损失、按月块重采样、共同结果表 |
| `runtime.py` | 输出路径保护、旧行情前缀、官方验证访问防护、来源与环境记录 |
| `report_unified_study.py` | 运行99配方、验证共同队列、统一评分、与报告冻结统计对照 |
| `verification.py`、`scripts/verify_report_unified.py` | 独立算术重放、混合平方误差恒等式、参数/时间/支持/哈希检查，不重新训练 |
| `pp_calendar`、`macro_multiplier_features.py` | 已公开公告证据、跨公告与阶段特征；不使用公告后数值或未来行情 |

已移除GAM/EBM、旧GBDT分类、静态分布、合同残差、早期两阶段分支及其旧结果和CLI；仍有用的H0、评分、重采样、市场读取等逻辑已抽为上述公共组件。源码快照包含审计、数据、模型、公告、配置、测试和核验工具。

## 复现与后续边界

当前运行生产者为`report_unified_v2`（数据为flat v2，日期协议仍为v3）。它重新拟合既有配置，以当前发布的99模型统计为回归参照；数据、参数和聚合不再依赖旧模型运行目录。目录存在即拒绝覆盖，读入的新格式数据经全套哈希和结构校验。

正式报告数字仍归属于原统一运行`report_unified_v3_20261015_r2`；重构复算用于证明没有改变结果，不构成新的模型试验。旧运行的源码和核验方式按其自身版本追溯，不能拿当前校验器强行验证旧存储格式。若要增补样本、调参、修改时间口径或做无标签部署，需另行建立实验。

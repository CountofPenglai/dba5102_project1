# 统一数据划分与训练模块：重构核验

日期：2026-10-18。此次只调整代码组织和训练复用，不改变模型公式、混合比例、特征、验证样本或报告结论。

## 公共模块与调用

| 模块 | 统一负责的内容 |
|---|---|
| `pp_data.splitting` | 校验唯一日期协议，生成预测窗口，筛选当时可用的训练订单 |
| `pp_models.training` | 单次运行内复用同一周的H0及时间衰减版本，记录实际拟合和缓存命中次数 |
| `pp_models.validation` | 统一日期、方向、期限和月初尾部参考等评价上下文 |
| `pp_models.forecast_history` | 保存前向预测，只在订单已结算后释放历史误差供动态混合使用 |

时间衰减、小时金额、状态回退、粗粒度混合研究共用一个`TrainingSession`；细粒度混合沿用已有参数回放，统一调用窗口和评价上下文。公告仅使用创建时间生成窗口，不读取结算或赔付标签。各研究分支仍可单独调用。

使用说明和Python示例见[统一训练架构](../training_architecture.md)。最终预测入口仍为`python -m pp_pricing`，研究入口仍为`python -m pp_models`。

## 保持不变的时间边界

- 4月训练，5–7月验证，从5月1日起连续每7日更新；跨月不重置时钟。
- 训练历史为此前30日创建、且在更新时点之前严格完成结算的订单。
- 动态混合保留28日对齐的前向预热；只使用预测后已知的历史误差。
- 月初尾部参考使用4月以来、月初前已结算的历史，不进入模型输入。
- 新数据池或新协议必须使用新会话；数据内容或协议被修改时拒绝复用缓存。

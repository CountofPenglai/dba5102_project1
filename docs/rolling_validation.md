## 2. 固定四个对照

1. `official_raw`：API Base 原值。
2. `grouped_mean`：过去 30d、方向×标称期限均值，k=30 向总体均值平滑。
3. `direction_scaled`：Put/Call 分别拟合非负 `c=sum(B*y)/sum(B²)`，预测 `B*c`。
4. `terminal_static`：复用已冻结的静态到期分布修正，lambda=0.01；仅 <=8h Put 使用 `a*Base+b*Proxy`，其余保持 Base。它是既有候选参照，不能声称该超参数未受六月观察影响。

上述方法使用完全相同的每日训练与评分订单。另切出旧六月前/后段 cohort 核对对照复现，不用旧分段选新模型。

## 3. 三项小型候选

`hurdle_base` 将零赔付保留在发生概率中：

`mu(x)=P(y>0|x)*E[y|y>0,x]`。

方向独立。概率用强正则 Logistic，C=0.1；只有 log(Base)、log(剩余期限)、方向对齐的标准化 moneyness 三项。moneyness 用 1h 已实现波动平方根按剩余期限缩放，原值截断 ±5；特征中心和尺度仅拟合当天合法同方向历史，标准化后截断 ±3。正赔付强度使用 `Base*s`，s 仅从同方向正赔付历史的原单位平方误差闭式拟合。没有额外市场信号、复杂强度回归或参数搜索。

同方向历史全零时 p=0、强度为零；全正时 p=1；没有同方向历史时显式回退 Base。相应次数与训练样本数记录，不任意删除零赔付或缺失方向。

`direction_shrunk` 检验降低历史拟合倍率幅度是否改善常态和冲击后高估。目标为归一化平方误差加 `(c−1)²`，lambda 固定 1，得到 `c=(c_OLS+1)/2`。这是统计收缩，不是加价余量，也不是硬价格上限；会同时削弱上调和下调，可能加重峰值低估。

`day_balanced_shrunk` 保持相同收缩，训练权重改为 `w_i=1/n_(方向,创建日)`：每个有该方向已结算订单的创建日总权重相同。闭式倍率为 `c=[sum(w*B*y)/sum(w*B²)+1]/2`。它减少成交数量集中的日期占据训练目标的程度，不能保证大额冲击不再影响结果，也不能保证更快恢复。与未加权的 `direction_shrunk` 对比，区分日权重和收缩两种作用。

所有三个候选仍用 30d 历史，不增加外部信号、商业余量、手工按峰值日指定的系数或更长训练窗。

## 4. 评价及提前结算诊断

- 全三个月 pooled RMSE/MAE/金额高估与低估，并分别汇报月、方向、期限、尾部。
- 月等权 `macro RMSE=sqrt(mean(月RMSE²))`、`macro MAE=mean(月MAE)`；它们与按订单汇总不同，避免六月样本多主导比较。
- 高额标签仅用于评价：预测日前合法历史同方向同期限 q90，n<30 回退同方向，再不足则 unavailable。不得把高额标签当作输入。
- 冲击后诊断使用当时已知的损失：某方向最近 3 个创建日中，有已结算订单的日均单位赔付超过此前 27d 日均单位赔付 q90，且旧历史至少 10 个有值日，则标记 `recent_high_loss`。这不是“当前行情风险已恢复”的判断，也不进入模型。
- 实际持有期/合同期限分为 `<50%`、`50–95%`、`95–105%`、`>105%`；只在预测完成后作诊断，不将真实关闭时间输入模型。不同组受用户选择和行情影响，不做提前终止的因果结论。
- 对 <=8h 两方向，独立用静态到期分布构造正赔付概率和无条件赔付代理。比较该概率、历史概率和 hurdle 概率的 Brier/log loss；分提前结算组评价代理误差。它是研究映射错配，未建立提前终止行为模型。
- 不把预测均值未覆盖单次峰值直接判为模型失效；同时检查尾部、普通订单与高损失后时段，不能靠少数大额日期改善就升级。

## 6. 首轮结果与独立核验

已完成 `rolling_calibration_apr_jun_20261009`。两步模型相对 Base 的月等权 RMSE/MAE 改善约 1.49%/6.36%，但高额 Call 更差、总金额低估未消失；对均值对照的月等权 RMSE 优势只有约 0.05%。收缩降低部分事后高估，同时削弱峰值；交易日等权无进一步整体增益。保留四个对照与两步候选，不升级主模型。[完整报告](../outputs/model_studies/rolling_calibration_apr_jun_20261009/reports/evaluation.md)。

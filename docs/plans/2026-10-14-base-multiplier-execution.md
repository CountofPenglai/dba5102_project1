- 比较 constant、contract、market（三者分别为常数、合同、合同＋市场）；Call 恒等于 Base。
- 主范围 `[0.9,1.1]`，正则强度固定 `[0.1,1,10]`，每类3组。截距也正则化。以训练 Put 赔付的均方根归一化损失；包括所有零/正赔付。
- 用线性 g、训练均值/标准差、标准分截断 ±3。为稳定求解，训练时增加 `-delta <= g <= delta` 的线性约束；这是比仅截断输出更保守的凸二次问题。预测时仍截断倍率。无约束解可行时直接使用，否则 SLSQP；优化失败则停止。
- 全体 Put 至少100单、10个创建日；每种标称期限至少30单、5个创建日才修正。合同/市场所用原始变换特征任一超出训练 min/max 或缺失时回退1；常数只受期限支持限制。每类覆盖不同，须披露。
- 合同特征：log(remaining_seconds)，`-log(S/K)/(total_RMS_240*sqrt(remaining_minutes))`。市场再加 log(down_RMS_240)、`-log_return_60/(total_RMS_240*sqrt(60))`；分母下限1e-6、log波动下限1e-12。
- 月初可用历史为 created、closed 都严格早于起点；倍率使用全部此前共同样本，H0 保持30天配方。4–6月每月独立起点，月内无标签反馈。
- 每类优先在 MAE 不超过 Base 的主范围配置中选月等权 RMSE 最低者；若均不满足则保留最低 RMSE 的失败对照，不自动采用。并列选较强正则。选参不能查看7月。
- `[0.8,1.2]` 只沿用各类主范围选出的正则，作敏感性对照，不再选参。记录选择后才解封旧7月；7月仅压力复查，不能重调。另做5月1日起连续冻结至旧7月末，检验更长无反馈期。
- 评分尾部：起点前所有已结算共同样本的方向×标称期限 q90；单元不足30单退到同方向，仍不足则不可评价。所有模型共享阈值，月内固定。普通/尾部按事后赔付划分，仅评价使用。
- 比较 Base、原 H0；分别报告全体、Put、Call、Put普通/尾部、月份与期限。主排名为月等权 RMSE（各月MSE均值开方）和 MAE；现金指标按实际数量累计。

# 宏观公告日历与旧数据诊断实施计划

本轮用户已授权：维护独立CPI/非农/FOMC日历至最新公开日程；仅用旧数据分析合同跨公告、市场波动与Base误差，不训练，不访问新官方验证。沿用项目既有诊断框架，在当前目录新增文件，不迁移未提交研究、不自动提交。

## 固定口径

- 数据集：`external_data/macro_events/`，源证据、版本快照、当前日历与字段说明分开。采用JSON作为可维护主数据，UTC由America/New_York时区计算。记录事件ID、参考期、事件家族、当地/UTC时间、状态、来源、抓取时间、最迟已知时间及证据。FOMC声明14:00和记者会14:30分开；未来日期标记scheduled/tentative，不把惯例推定的时间写成逐场核实。
- 覆盖：收集2026、2027官方年历以及官方已公布的2028年1月FOMC。未来缺日历应返回未知，不能解释为无事件。不存公告经济数值/市场预期，不借新官方订单集确定日历范围。
- 信息时点：旧4–7月CPI/非农用前一期新闻稿的下次发布时间证明事前已知；FOMC用2024年公开的2026日程和公开声明/记者会时间规则。当前抓取时间不能冒充历史获知时间；其余日期未核实历史预告则保留unknown。
- 订单：复用旧4–7月risk6615/共同Base5494与原行情前缀哈希，实际赔付仅作事后标签。主定义为`created < announcement <= created + remaining_seconds`，不依赖实际closed。公告同刻买入不计跨越；实际存续至公告只作事后诊断。
- 市场：以分钟收益计算公告后15/60/240分钟RMS、上下行RMS及累计收益；与公告前同长窗口及±7/±14天同纽约时刻比较。控制窗口须完整、不越旧行情范围、不与本轮其他主要公告窗口重叠。主事件为CPI/非农/FOMC声明，记者会仅补充，不能当作独立FOMC事件翻倍计数。
- 合同未来市场波动：只统计创建后、计划到期前完整分钟，排除部分分钟，不用实际持有期；覆盖不足不输出波动值。
- Base：按方向、月、事件类型报告订单数、独立事件数、实际/Base均值、偏差(Base−实际)、RMSE/MAE、尾部率及现金低估。原始跨公告/非跨公告仅为描述。
- 对照：对每个公告及±7/±14天同当地时刻的伪事件，找计划期跨过该时刻的订单；伪事件同月，订单不得跨过真实主要公告或落在真实公告后4小时内。先按方向×精确名义期限×距公告时间分组，再加入价格位置和事前方向波动分组；以真实跨公告订单分布加权。报告覆盖损失，无匹配不补值、不训练回归。
- 稳定性：事件等权，报告逐事件结果、事件贡献及删除任一事件的范围；至少8个事件才给2000次事件重采样区间，少事件只报告描述，不把同事件多订单当独立证据。区间为探索性、未多重校正，事件仍可能受共同市场状态影响。
- 旧7月已见，单列压力复查；本轮不输出预测倍率、不改变模型采用条件。

# H0 时间衰减：4 月训练、5–7 月滚动验证

用户授权：给 H0 历史样本加入时间衰减，每 7 日更新，暂不叠加残差；与原 H0、Base 比较。4 月纯训练，5、6、7 月滚动验证。新官方验证集不访问。

## 固定设置

- 新协议 `rolling_validation_v3` 单独维护。canonical 预处理和旧实验的日期语义不改写；其存储为 test 的旧 7 月，在本协议明确用作验证，不再称独立测试或压力期。
- 训练订单最早 2026-04-01 UTC。预测从 2026-05-01 起，每 7 日更新，跨月连续推进：5/1、5/8、…、5/29、6/5、…、7/31；周内冻结。结束于旧数据边界 2026-07-31 17:11:48 UTC（右开）。
- 每次训练只用创建于此前 30 日且严格在更新前结算的订单。后续验证订单结算后可在下一次更新进入训练；不使用当前周或尚未结算标签。不使用 4 月前标签。
- 四组固定模型：Base、原 H0、7 天半衰期 H0（主方案）、14 天半衰期 H0（敏感性）。不做搜索或结果后换参数。原 H0 按相同新网格重新拟合，不搬用旧 4/1 网格结果。
- H0 保持 Call/Put 独立 Logistic 概率（C=0.1）× 正赔付样本 Base 金额系数。只改两个阶段的样本权重。
- 原始时间权重 `w=2^(-(更新时刻-创建时刻)/半衰期)`。以创建时刻计龄，结算时刻仅用于标签可用性。概率权重在每个方向归一化到总和为该方向订单数，保持正则强度可比；金额系数 `sum(w*Base*Y)/sum(w*Base²)`，仅正赔付样本。
- 标准化器仍在该方向全部合法历史上无权重拟合，保留原设计、截断和正则；这样实验只改变损失中的历史相对权重。无该方向历史沿用 Base 回退，全零赔付方向预测 0。
- 尾部标签仅用于事后评价：每月初用 4/1 起已创建且已结算的历史，方向×期限 q90；不足 30 单退方向，不足则标记不可用。同月所有候选使用同一阈值，周内不更新尾部定义。

## 评价与输出

RMSE 优先，MAE 为代价监控；报告月等权、全期逐单、各月、Call/Put、普通/尾部、期限以及实际现金累计少估和净偏差。历史 2% 尾部/少估上限、绝对净偏差不扩大作为工作检查，不是官方要求，且不自动选择模型。

保存每次拟合的参数、有效样本量、正样本数、时间权重、历史各月对金额系数分子分母的贡献；Brier、正样本金额误差及固定另一阶段的预测分解用于诊断，不构成新增候选。

预设五对比较：H0 对 Base，两种衰减各对 H0/Base。按月分层的 3/7/14 日块 bootstrap 2000 次，至少 1900 有效次；给出 95% 区间及本轮五比较整体 RMSE 同时区间。删 1/7 天检查稳定性。不能将这些已反复探索的数据称新样本确认。

仅保存聚合、每日充分统计、参数和来源，不保存逐单预测。新入口与配置独立，不覆盖旧输出。无需 GPU；预计 CPU 秒至分钟级。

## 执行与验证

1. 先写权重/闭式系数/原 H0 一致性/前向标签隔离/4 月边界/连续周历的失败测试，再实现。
2. 固定配置运行四组；源文件与 canonical 数据做校验，禁止新官方验证访问。
3. 独立参数重放：不调用 fit，核对训练边界、权重归一化、金额闭式系数和所有汇总指标；全测试、独立代码审查。
4. 记录结果、限制与是否值得保留，更新 README/索引/决策记录；不自动组合、部署、提交或推送。

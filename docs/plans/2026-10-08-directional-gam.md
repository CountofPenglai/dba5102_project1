# 多窗口与方向 GAM：实施与执行记录

依据：`docs/research_decisions.md` 第 14 节。用户已要求按计划重跑；本文件固定实现细节，不再增加审批步骤。

## 固定实验

- risk、无 Base；原 v1 样本 ID、日期、30 天已结算历史、原始尺度平方误差不变。
- 调参 6 月 1–20 日，后段评价 21–30 日，标签须在各阶段结束前可获知；整个新实验标为后续探索。
- 四个 GAM：A 原已选配置；B 多窗口共享曲线；C B 加方向差异曲线；D C 的总波动替换为上行与下行波动。
- B/C/D 使用 1、4、24 小时收益与波动，波动采用每分钟平方收益均值的平方根。期限、moneyness、现价保留。
- C/D 采用共享平滑曲线加 Put 指示变量乘以差异曲线；差异基函数只在当日合法 Put 训练行上中心化，预测时复用中心值；现价曲线保持共享。方向线性项继续使用同一惩罚，避免同时改动方向截距惩罚。差异曲线不单独声称为因果解释。
- 所有版本 n_splines=4、max_iter=100、tol=1e-4；A 固定 lam=100，B/C/D 各比较 lam=10/100/1000。每个版本独立按调参 RMSE 选参，最佳 1% 内优先更强平滑。先固定所有配置，再读后段评价结果；另保留 lam=100 的固定参数对照以区分结构与调参作用。
- 10 个调参候选、4 个已选后段版本，另有最多 3 个 lam=100 后段结构对照，共最多 270 次每日 GAM 拟合；B0/B1 60 次更新。不训练 EBM/树，不加保守余量，不读测试 CSV。
- 只保存分组/每日关键统计、有效自由度/收敛诊断及复现来源；不保存逐笔预测、每日模型或补充特征全表。

## 实施任务与接口

1. `pp_models/directional_features.py`：`read_market_prefix(path, cutoff)` 仅摄取截止前行情；`directional_features(created, usable, windows)` 按过去完整连续分钟计算方向波动；`augment_pool(pool, usable)` 精确对齐 canonical ID 并核对总波动。原 pp_data 不变。
   - 测试手算正负分解、统一尺度、未完成/未来 K 线不影响特征、缺口不填补、缺特征明确失败；前缀读取仅检查首个越界行的时间，不解析其行情值，不遍历未来尾部。
2. `pp_models/directional_gam.py`：固定白名单与四个结构；复用 PayoutRegressor 的目标、非负修正、收敛检查。测试输入拒绝答案字段及方向改变响应斜率；诊断输出有效自由度和最终迭代差值。
3. `pp_models/evaluation.py`：仅在显式开启时增加逐日 Call/Put 统计和模型诊断，原入口默认行为保持。测试分组金额与总体相加一致、既有时点测试继续通过。
4. `pp_models/directional_study.py` + `config/gam_directional_v1.json`：独立明确入口，复用 scoped 数据读取、daily evaluator、TrialStore；保存配置与来源校验，测试调参先于后段、配置锁定、同订单评分、结果文件校验和测试集访问拦截。
5. 全套测试、独立代码审查、运行；按总体/方向/日期/期限评价，与首轮和 B1 比较，记录收益与代价，不追加事后搜索。

## 审查重点

- 前缀边界、分钟连续性、订单创建时点、行 ID 和原总波动的一致性。
- 方向 by 项是否改变斜率，而非只改截距；有限搜索是否混入后段结果。
- 日分组新增行不得重复累计拟合次数或污染基准胜率；没有测试 CSV 读取和事后输入。
- 首轮可复现误差、结果出处和复现代码身份；不把反复观察后的六月当作独立验证。

## 审查重点

1. 小 Base 放大 `Y/Base`：记录合法训练集中的比率分布及异常预测，不能按事后赔付删除订单或截断目标。
2. 某方向无历史、全零或全正赔付：概率及金额回退与 H0 一致，不伪造成功拟合。
3. 金额阶段样本不足或数值失败：显式回退 H0 金额并汇总原因；输入错位或非法数据应报错。
4. 特征尺度与裁剪：只在当天同方向正赔付历史上拟合金额阶段标准化；不能使用评分数据或概率阶段的缩放参数。
5. 相同候选不同评分队列：共同名单、尾部分组和预测对齐必须一致；缺失某组应显式报告无样本，而非省略失败结果。

## 分支1：合同条件化的正赔付金额估计

### 1. 研究问题与固定模型

当前 `mu=p_d(x)×B×c_d`，同一天同方向的金额倍率 `c_d` 相同。研究问题是：**在 Base 已包含部分合同信息之后，剩余期限和价格位置还能否解释正赔付金额相对 Base 的差异？** 不能预设一定存在增量。

`Y` 为每 BTC 实际赔付，`B` 为官方 `api_base_price_per_btc_usdc`，`d` 为方向（`option_type=0` Call、`1` Put）。金额阶段只用合法历史 `Y>0` 的订单；最终 `mu` 的评价保留全部订单，包括零赔付。

概率阶段逐日复用 `CalibrationModel('hurdle_base')` 的概率输出：Logistic `C=0.1`，以及既有特征、缩放、裁剪、单一类别和无历史回退。新增候选不得各自改变概率拟合设置。

新增金额阶段拟合 `R=Y/B` 的 Gamma 均值回归，使用 log link：`s=B×exp(a_d+beta_d'z)`。它是正值均值工作模型，不宣称目标服从 Gamma 分布。最终仍按原 USDC/BTC 尺度评价。

| 候选 | 金额阶段 | 作用 |
|---|---|---|
| H0 | `B×sum(BY)/sum(B²)`，求和限历史正赔付 | 必须超过的现有模型；原金额回退 |
| G0 | `B×mean(Y/B)`，均值限历史正赔付 | Gamma 仅截距对照，区分拟合损失变化 |
| G1a | G0 的 log-link 形式加两个合同变量，`alpha=1` | 检验合同条件化 |
| G1b | 同 G1a，`alpha=10` | 更强正则的固定候选 |

G0 使用上述闭式解，无需迭代优化。H0 与 G0 的权重/损失不同，因此 G1 超过 H0 不能单独证明合同特征有价值。

### 2. 两个合同变量

1. `log(remaining_seconds)`：定价时的合同剩余期限，不是后来观察到的实际持有时间。
2. 方向对齐且按历史波动标准化的价格位置：复用 `hurdle_design` 的第三列，即
   `clip((1−2×option_type)×log_moneyness / max(realized_vol_60m×sqrt(remaining_seconds/3600),1e-6),−5,5)`。

金额模型的两个变量仅在当天同方向正赔付训练样本上标准化，再裁剪至 ±3；评分时使用同一转换。方向分别拟合，期限共享样本。不加入交互项、市场变化速度、订单活动或客户特征；不强制期限和倍率之间的单调关系，因为 Base 已经包含部分期限信息。

### 3. 样本支持和回退

- 沿用总计划拟定的支持度：每个方向至少40笔正赔付、至少5个不同创建日期；不足时 G0/G1 回退该日该方向的 H0 金额。支持度是研究设置，不是统计充分性的保证。
- 无该方向历史、全零或全正标签时，保持 H0 的概率处理；全零时金额为零，无历史时沿用 Base 回退。
- 收敛失败、非有限或非法金额预测显式记录，并对该日该方向回退 H0 金额。数据格式、时间错位、目标错位不能用模型回退掩盖。
- 不裁剪真实赔付或比率目标，不删除大赔付订单；不在看到开发成绩后追加金额上限。

### 4. 评价和采用规则

**两层比较分别报告：** G1a/G1b 对 G0 回答合同特征是否有增量；所有新增版本对 H0 回答模型是否值得替换。官方 Base、方向×期限均值与简单方向倍率保留为共同样本对照。

- 主指标：月等权 RMSE `sqrt(mean(月RMSE²))`；关键辅助为月等权 MAE `mean(月MAE)`。同时列合并订单指标。
- 替换 H0 的必要条件：月等权 RMSE 严格低于 H0，月等权 MAE 不高于 H0。仅超过 Base 不采用；不因单项峰值指标好看而放弃整体条件。
- 报告逐月、Put/Call、期限、历史 q90 尾部与其余组，以及剔除任一创建日后的改善变化；主成绩始终保留峰值。月度稳定性及小改进的简洁性门槛仍属后续选择规则讨论，不能把原草案的0.5%写成已确认门槛。
- q90 使用现有相同方向×期限历史及最少30笔/方向回退规则，不能按各模型重新定义尾部。
- 按订单 BTC 数量换算，报告预测/实际总额、绝对总额偏差 `abs(sum(q×(pred−Y)))`、累计低估 `sum(q×max(Y−pred,0))`、累计高估 `sum(q×max(pred−Y,0))`。前者不能代替逐单低估。
- 单独列最终风险约束的工作提案检查：各方向尾部 RMSE、累计低估不高于 Base 的1.02倍，绝对总金额偏差不比 Base 扩大。2%是暂定研究容忍，不是官方规则；H0 本身也不能被默认视为通过这些约束。风险约束未通过的候选不能直接称为最终可交付模型。
- G0 若胜过 H0 而 G1 未胜过 G0，只能说明拟合方法变化有帮助；不得称合同特征有效。G0 可作为更简单候选继续接受同样约束。
- 全部失败时保留 H0，不扩大参数搜索。分支失败可能意味着 Base 已吸收信息、样本不足或工作模型不合适，不能直接断言合同与赔付无关。

## 分支2：方向波动信号的额外增量

### 1. 研究问题与唯一新增信号

**在 Base 和合同条件相近时，近期风险方向的波动增强，能否解释更高的正赔付金额？** 当前 Base 及波动标准化价格位置已经包含部分波动信息；本分支检验额外增量，不以波动和赔付的简单相关性代替前向效果。

只增加 `directional_acceleration = log((risk_RMS_60m+1e-12)/(risk_RMS_240m+1e-12))`：

- Call（`option_type=0`）取 `up_vol_60m`、`up_vol_240m`。
- Put（`option_type=1`）取 `down_vol_60m`、`down_vol_240m`。
- 复用 `pp_models/directional_features.py`：一分钟 log return 对相反方向取零，平方后按窗口全部分钟取均值再开方。不能直接用未调整窗口归一化的 `realized_vol_60m/realized_vol_240m` 替代。
- 大于零表示短窗口风险方向 RMS 高于长窗口，小于零表示相对缓和；不等同于连续上涨/下跌，不等同于绝对高波动。
- 只用订单创建时已经完成且连续的 K 线。未来行情改变不能影响既有订单信号；时间对齐或连续数据缺失应显式报错，不能静默减少共同样本。

### 2. 固定候选与日内更新

| 配对 | 合同模型 | 加信号后的模型 | 固定正则 |
|---|---|---|---|
| a | G1a：两个合同变量 | G2a：两个合同变量＋方向波动变化量 | `alpha=1` |
| b | G1b：两个合同变量 | G2b：两个合同变量＋方向波动变化量 | `alpha=10` |

概率阶段与分支1完全相同。新增信号只进入金额阶段，`s=B×exp(a_d+beta_contract'z_contract+beta_market×z_acceleration)`；仍只用当日合法历史正赔付训练，Put/Call 分别拟合。标准化、±3裁剪、40笔/5创建日支持度、异常回退全部沿用分支1。

不限制市场信号系数为正；系数方向与跨月稳定性作为诊断，不能因符号符合直觉就判定有用。不加入交互、绝对波动门控、订单频率、硬报警、只涨不跌规则或安全余量。

每日只更新一次回归系数；每笔新订单根据创建前已完成的分钟 K 线计算新信号。因此可以日内响应，但60分钟窗口仍有平滑与滞后；本轮不搜索更短窗口。修正是当前特征的函数，不保留前一笔订单的累积倍率。

### 3. 评价与采用

- 首先报告 G2a−G1a、G2b−G1b 的配对差，保持同一 alpha，不能将正则变化解释为信号收益。
- 采用仍须月等权 RMSE 低于 H0、MAE 不高于 H0，并超过分支1保留的更简单候选；若只改善 G1 却仍不如 H0，不替换。沿用分支1的 Base 风险约束检查，区分特征增量、模型替换与最终约束通过。
- 若分支1没有可采用的新候选，H0 仍是必须超过的对照；G1a/G1b 仍用于诊断配对，不因此自动新增“仅市场信号”模型或扩大组合。
- 所有订单参与最终评价。除整体、月份、方向、期限和历史 q90 尾部外，检查峰值附近以及冲击后高估，报告剔除任一创建日的影响。峰值日期只用于事后解释，不能成为输入、门控或选窗口的依据。
- 诊断相对放大是否造成误判：按方向报告 `A>0` 且绝对 `risk_RMS_60m` 不高于当天同方向合法历史订单中位数的样本数、创建日数、误差及累计高估。该切片是“相对增强但绝对波动仍低”的检查，不直接称为误报，也不用于触发或调整倍率。中位数只取预测日前合法历史，不能使用整个评分期计算。
- 同时报告 `A>0`、`A<=0` 的支持度与配对误差，避免只展示有利切片；金额阶段系数及回退率保留概要即可。
- 承认边界：反转和震荡会使方向波动与最终赔付分离；没有前兆的首次跳变无法保证提前捕捉；统计系数不是因果解释。未见稳定增量则保留简单候选，不追加窗口或触发阈值。

### 2. 固定四档与顺序

用户认为原候选档位过粗，明确增加 `lambda=0.25`。第三分支候选范围更新为 **`1、0.5、0.25、0`**，预测公式保持 `mu_final = Base + lambda_d × (mu_R − Base)`。

| lambda_d | 保留模型相对 Base 的修正 | 对应预测 |
|---|---|---|
| 1 | 100% | `mu_R` |
| 0.5 | 50% | `0.5×Base + 0.5×mu_R` |
| 0.25 | 25% | `0.75×Base + 0.25×mu_R` |
| 0 | 0%，完全回退 | `Base` |

每个方向按 **`1→0.5→0.25→0`** 检查，前一档未通过才检查下一档；在全部方向条件通过的第一档停止。支持度不足则直接回退 Base。不是遍历16种方向组合挑分数最高者。新增0.25档提供完整回退前的较小修正，它表示保留25%模型修正，不是额外加价25%。

| 该方向全部订单 MAE | 不高于 Base |
| q90非尾部订单 MAE | 不超过 Base 的1.02倍 |
| q90尾部 RMSE | 不超过 Base 的1.02倍 |
| 按 BTC 数量换算的累计低估 | 不超过 Base 的1.02倍 |

## 分支4：三层概率对照与归因消融

### 1. 研究问题与三层概率

用户认为只用同方向历史频率作为对照过粗，确认增加方向×期限平滑频率，并将平滑参数固定为30。本分支检验：Logistic 是否优于合理的简单合同分组，以及金额改进是否依赖特定概率模型。历史频率仅作为消融对照，不替换当前主模型。

对每日 D，所有计数仅来自原协议允许的30天共同 benchmark 历史，必须已在 D 前结算；正例为 `Y>0`，不能只在正赔付订单中计算概率。方向 d、标称期限 t 使用 `option_type`、`product_duration_seconds`，不是实际持有期。

| 概率对照 | 固定定义 | 用途 |
|---|---|---|
| `direction_frequency` | `p_d=N_positive_d/N_d` | 忽略同方向合同差异的基础诊断 |
| `direction_tenor_frequency` | `(N_positive_dt+30×p_d)/(N_dt+30)` | 主要简单对照；期限小组向同方向频率平滑 |
| `logistic_probability` | 现有 H0 的逐单概率 | Base、剩余期限、方向标准化价格位置的条件预测 |

期限组无历史时回退 `p_d`；方向无历史时沿用 H0 的兼容回退概率1，并显式记录 `no_direction_history`，不能将它解释为估计出100%赔付率。方向历史全零/全正时频率自然为0/1；Logistic 保持原单一类别处理。固定30只作用于期限组平滑，不另加概率平滑参数，不搜索期限分箱、窗口或市场状态分组。

**与旧报告的口径差别：** `rolling_study.py` 的旧概率诊断使用 `(N_positive_d+0.5)/(N_d+1)`。新基础对照按本次确认的原始频率定义，必须新算并使用上述明确名称，不能直接复制旧 Brier 数字。旧报告及旧模型实现保留原样。现有 `RollingMean` 的分组均值则向全局均值平滑；新概率对照明确向同方向频率平滑，不能直接复用其全局先验而不区分方向。

### 2. 三层概率×两种金额的固定矩阵

`s0` 为 H0 原正赔付金额，`sR` 为前两分支保留的 R 的正赔付金额。先使用未收缩预测：

| 概率 | 原金额 s0 | 保留金额 sR |
|---|---|---|
| 方向频率 | `direction_frequency_s0` | `direction_frequency_sR` |
| 方向×期限平滑频率 | `direction_tenor_frequency_s0` | `direction_tenor_frequency_sR` |
| Logistic | H0 | R |

最多六个组合，其中 H0/R 已存在，新增四个简单对照。若 `sR=s0`，去重并明确本轮没有新的金额贡献，不为凑齐矩阵强行采用新模型。

固定同一日、同一金额列内的 `s0/sR` 输出；替换概率时不再调整金额系数来补偿。金额阶段仍只用合法历史正赔付拟合，全部订单用于最终赔付评分。

按两个金额列分别比较 Logistic 与方向频率、方向×期限频率，后者为主要概率增量对照；按三个概率行分别比较新旧金额，检查金额改进是否依赖特定概率。金额特征贡献仍须沿用 G0/G1/G2 配对证据，不能把换 Gamma 损失的收益归因于特征。

最后单独比较未收缩 R 与第三分支最终组合，说明约束层的代价及收益；不为每项消融重新选择方向档位。完全回退 Base 的方向不能把原始两阶段优势计入最终输出贡献。

### 3. 评价与结论边界

- 概率层：三种概率的 Brier、log loss、固定概率分箱的平均预测与实际正赔付率，并报告支持度；复用统一指标计算约定。不得把更低 Brier 单独称为校准更好。
- 金额层：仅在评分期正赔付订单上比较 `s0/sR` 的 RMSE、MAE；金额列的结果不因概率替换而改变，不能重复作为多份证据。
- 整体层：六个未收缩组合使用相同全部评分订单，报告月等权 RMSE/MAE、合并误差、方向/月度/期限/q90尾部，以及金额偏差和累计高估/低估。不能用正赔付子集成绩替代整体效果。
- Logistic 若只胜方向频率而不胜方向×期限频率，只能说明区分合同可能有帮助，尚不能证明其相对简单分组的额外价值。概率指标和最终赔付指标的结论可能不同，必须分开表述。
- 两阶段相乘，改进可能互相补偿；不得机械相加改善百分比，不能将预测消融解释成经济因果效应。
- 消融不重新挑选主模型。若简单分组更好，完整报告为对当前结构的反证，收窄贡献主张；不隐瞒、不自动把它加入新的选参轮次。后续若要改主模型，另行明确研究范围。
- 沿用4–6月开发期、7月保留以及仅关键统计输出；本分支不新拟合额外回归家族、不调整概率 C、不调整平滑参数30。

## 分支5：稳定性、不确定性与良好分支的补充验证

### 1. 目标与已确认原则

检验已观察的改善是否跨时期稳定、是否依赖少数日期，并描述配对误差差值的不确定性。本组不增加模型、不重新调参。用户确认：**点估计优于 H0、风险约束通过，但改善幅度的95%区间跨0时，保留候选并明确“增益尚不确定”，待后期测试确认；不把区间跨0直接当作淘汰条件。** 这不等于已证明显著优于 H0，也不放宽点估计和风险条件。

用户另外要求：**对前面验证表现良好的分支也应用本组补充验证，不能只检查最终组合。** 各分支仍遵守原本的采用规则；本组为其正向结论补充证据，不是新增择优轮次。

### 2. 比较登记与覆盖范围

先依据前面各分支已经记录的点估计、增量及风险条件，登记全部版本及进入/未进入补充验证的理由；再计算区间。所有被保留或拟在报告中主张有正向增量的版本都必须进入，不能看到区间后挑选。落选版本的原始结果和理由仍完整保留。

| 对象 | 必须保留的配对关系 | 主要解释 |
|---|---|---|
| 最终候选（如存在） | 对 H0、Base、方向×期限均值 | 整体改进及复杂度价值 |
| 分支1良好版本 | G1对G0，以及新版本对H0；若仅G0良好则G0对H0 | 区分合同增量与拟合方法变化 |
| 分支2良好版本 | G2a对G1a、G2b对G1b；并列H0及分支1保留候选 | 同正则下的信号增量及可采用性 |
| 分支3通过组合 | 最终组合对R、H0、Base | 风险约束收益与精度代价；不要求对R的RMSE也改善 |
| 分支4正向贡献 | 同金额列内概率配对、同概率行内金额配对 | 主要概率对照为方向×期限平滑频率；不借消融换主模型 |

重复配对去重。对“仅局部指标改善、尚未达到模型采用条件”的对象，状态应为局部证据，不能自动升级为最终候选。若没有通过采用条件的最终模型，照常检验已有良好分支并如实报告无最终候选。

统一定义差值为 `delta=候选指标−对照指标`，误差类指标负值表示改善。主区间为月等权 RMSE/MAE 差；若主张概率贡献，额外计算 Brier 差区间，不能用整体金额改善替代概率证据。风险约束仍按分支3原指标判断，并通过月份/方向表说明取舍，不用区间跨0来放宽约束。

### 3. 三类补充检验

**月份与方向。** 固定展示4、5、6月及各月Put/Call的配对差、订单数、创建日期数、尾部支持度。空组明确报告无样本；不要求每个小组都胜出，不事后挑有利月份重定义主成绩。

**日期影响。** 对每个配对逐一从评分汇总暂时排除一个创建日，再逐一排除连续7个日历日，重算既定月等权差值。窗口固定在4–6月完整日历内，保留无订单日，不按事件大小挑窗口。主结果保留全部日期；只保存差值范围、改变优劣符号的窗口数量及最有影响的日期/窗口。此处不改训练历史、不重训模型，也不解释为“市场没发生这次事件时会怎样”。

**配对时间块重采样。** 主设置7个日历日块、2,000次、种子20261012；固定3日/14日块敏感性，同样2,000次，全部展示。每月分别重采样，每次重算月等权 RMSE `sqrt(mean(月MSE))`、月等权 MAE，并计算两方法差值，不把已算好的RMSE直接取平均。每块携带对应日期的全部评分订单，各方法/配对使用相同日历抽样；不逐笔独立抽订单。

为使实现唯一，采用月内固定长度环形块：每块起点在该月全部日历日等概率抽取，连续取指定天数、越过月末时回到月初；拼接至该月原日历长度并截去多余日期。同一日重复抽中必须重复计权，无订单日保留为零订单计数，不能当作一笔零误差订单。月末接月初只是重采样近似，不代表真实市场时间相邻；3/14日结果用于检查该近似和块长度的敏感性。

95%区间取配对差重采样分布的2.5%/97.5%分位数。对空月份或指标零分母导致的无效重复记缺失、不补抽，并报告有效次数；实现支持度设为至少1,900/2,000次有效，否则该项区间记为不可估。使用有效重复的区间必须披露排除次数，不能把空组误差置零。该有效次数门槛只用于防止输出不可靠区间，不参与模型择优。

重采样使用已生成的预测/误差，不重训2,000次；日期影响分析也保持模型预测固定。必要时从锁定来源重建一次预测到内存，但不改变模型参数设置、训练协议或候选。

### 4. 证据分级及限制

- 点估计改善、7日主区间整体小于0：当前历史回放提供较强支持，仍是开发期证据。
- 点估计改善、区间跨0：保留满足原采用条件的候选，写明增益尚不确定，不声称显著优越。
- 优劣随单日/单周排除或3/7/14日块变化：明确标注事件依赖或设置敏感，不选择最好看的区间。
- 概率、金额、风险约束的改善分别陈述；收缩若以部分精度换取风险约束通过，不能把正的RMSE差藏起来。
- 多个良好分支是在已看过开发期结果后进入本组，区间仍存在择优影响；它们是逐项探索区间，不具有“全部结论同时95%可靠”的含义。不将更多消融/分组中偶然排除0的一项升级为确认性结论。
- 此分析不能消除反复开发、非平稳市场、有限极端事件或模型训练不确定性。4–6月不能重新命名为独立验证；之后仍须冻结配方与规则，再单独检验7月。

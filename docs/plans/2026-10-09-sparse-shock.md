# 稀疏冲击状态叠加：冻结首轮方案

用户批准方案 1，分别叠加官方 Base 与两步赔付模型。继续使用 v2 4–6 月逐日验证、30 天已结算历史，7 月保留。本文件在真实结果计算前固定；阈值与幅度设置不按本轮成绩追加搜索。

## 触发与恢复

完整 5m K 线更新，15m 有符号收益除以前 288 根 5m 收益 RMS×sqrt(3)，尺度排除当前根、下限 0.0001。Put 对负方向、Call 对正方向分别构造 z。每日 UTC 零点以此前 30d、可用时间严格早于 D 的行情 z 分位数设定门槛，至少 2,880 根有效历史；当日门槛固定。

- 普通启动：方向 z>=历史 q99、15m 同向对数收益>=0.003（约30bp）、当前5m仍同向；连续两根确认。
- 极端启动：方向 z>=q99.9、15m同向收益>=0.006、当前5m同向；单根启动。
- 普通启动状态为 0.5–1，按 z 在 q99–q99.9 之间线性映射；极端启动为 1。不是连续小跌累加。
- 活跃期间强证据刷新状态与30m有效期；弱证据为 z<q95、15m同向收益<0.0015、或当前5m不再同向。连续两根弱证据或者有效期过期后进入恢复。
- 恢复期间每5m乘以 sqrt(0.5)，即10m半衰期；状态低于0.05归零。恢复中重新达到启动条件可以再激活。没有新证据不能续期；数据缺口重置状态，并显式标记不可用。
- 事件 ID 从零状态启动到状态再次归零；恢复中复燃仍属同一事件。不将这些事件宣称为统计独立。

价格状态与订单方向匹配。合约权重为 `clip((aligned_moneyness+2)/2,0,1)`，其中 moneyness 是方向对齐的 log(S/K) 除以 60m 已实现波动×sqrt(remaining/3600)，分母下限1e-6。ATM及ITM权重1，深OTM减弱至0；这是固定启发式，不是已验证的风险概率。订单有效状态 g=市场状态×合约权重，所有订单保留。

## 幅度与对照

预测 `anchor*(1+A_direction*g)`。两个 anchor 为原官方 Base、既有固定两步模型。两步模型仍每日仅用合法历史拟合；为幅度训练，从3/2开始重放历史订单当时的基础预测，不使用今日模型对历史训练内拟合值。回放日基础历史不足100笔明确失败。

每日幅度仅用过去30天已结算订单；每个方向、每个已触发事件总权重相同。设 x=历史基础预测×g，A_OLS=max(0,sum(w*x*(y-anchor))/sum(w*x²))。至少3个有订单的历史事件、10笔有效订单；不足回退0。随后乘以 n_events/(n_events+5) 向零收缩，再截断到[0,2]，所以附加总倍率不超过3。大赔付标签不裁剪，没有正幅度下限。

四个主版本：`official_raw`、`official_shock`、`hurdle_base`、`hurdle_shock`。额外两项预先固定的诊断：相同门控但 A=0.5，分别叠加两个 anchor，用于区分“信号无效”和“稀疏历史学不到幅度”；不按结果将较好者追认为主模型。

另做每月×方向的事后等额加价参考：将响应方案增加的预测总金额平均分配为 anchor 的统一比例，保证同组总预算相同。这个对照使用整组未来订单构成，只是事后时机诊断，不可部署、不参加拟合或主模型排名；对照不得用赔付标签决定倍率。

## 评价和边界

所有版本相同2953笔/72天；输出整体、月、方向、期限、历史q90尾部、近期高损失、提前结算切片，以及触发/恢复/未触发切片。尾部阈值继承统一历史规则，仅作事后评价，不能用于触发。记录尾部发生率/召回/金额命中率、调整比例、增量高估/低估、状态恢复、幅度回退次数与事件覆盖。常规订单为同一历史尾部阈值下的 body，不能以“未触发”替代正常标签。

先看月等权和合并 RMSE/MAE，再看尾部低估及常规高估代价；不以单个6/24事件证明改进。市场状态恢复只撤销新增倍率，不能消除 anchor 自身偏高。新单调整不能改变已成交保单赔付。无需求模型、利润改善或无套利承诺。

采用 TDD 检验确认/极端启动、半衰期与有效期、未来行情不影响旧信号、只用完整行情、幅度稀疏回退/事件权重/上限、标签严格可得和四组共同样本。正式运行前冻结源码与配置；之后独立核对旧 anchor 复现、公式和汇总。

输出 `outputs/model_studies/ID/{metrics,provenance,reports}`，只保留关键聚合、参数/事件覆盖摘要、源码及哈希；无逐单预测、行情状态表、模型文件。不修改 v1 预处理，不读七月价格或测试 CSV，不自动提交推送。

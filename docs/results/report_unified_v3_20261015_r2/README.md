# Minimal numerical regression reference

This directory is not an active report or configuration. It retains only two historical tables read by `pp_models.report_unified_study.compare_reference`:

- `validation/summary.csv`: grouped metrics for the unchanged report models.
- `validation/model_comparison.csv`: headline metrics for the 96 unchanged recipes.

Retired announcement recipes have been removed; every retained cell value is preserved. Superseded run settings, duplicate diagnostics and old local full runs were removed on 2026-10-18. Original tracked files remain available in Git history.

当前报告和公告结果请使用[结果索引](../README.md)中的`report_announcement_v1_20261016`。此目录仅用于检查未改配方是否发生数值回归。

## 2. 配套依据与阅读顺序

1. 先读本索引，确认当前阶段及停止边界。
2. 读两份 Word，理解商业问题、报告框架和研究目的。
3. 读[两阶段研究总计划](research_plan_two_stage.md)，了解主线、历史证据和局限；其中保留早期工作提案。
4. 准备实施时逐项读[前五分支实施方案](plans/2026-10-12-two-stage-implementation.md)，核对模型、样本、评价和对应 prompt。
5. 有歧义时查[研究决策记录](research_decisions.md)第36–42节；同一问题以最新用户确认及对应详细方案为准，不沿用被后续讨论替代的早期草案。

[后期独立阶段方案](plans/2026-10-12-two-stage-post-development.md)是具体实施方案的配套文档，单独规定正式冻结、4–6月冻结参数回放、7月两种运行模式和离线部署检查。方案已确认，执行尚未启动；不能将其加入前五组默认流程。

## 4. 接手后不得改变的关键口径

- **样本与时间：** 当前开发评价仅限4–6月共同样本。预测日D只用此前30天创建、且D前已结算的合法历史订单；不改变原预处理排除规则，不启用7月评价。
- **信息边界：** 最终赔付可作为合法历史训练目标和事后评价标签；实际结束时间、实际持有期及未来行情不能作为定价输入。
- **模型采用：** 新版本月等权RMSE须低于H0，MAE不得高于H0，同时检查已确认的方向、尾部、普通订单和总金额约束。只胜Base不足以采用；2%是研究工作容忍度，不是官方规则。
- **证据强度：** 点估计及风险条件通过但95%改善区间跨0，可保留候选，须明确“增益尚不确定”。不得将开发期择优结果说成独立验证或真实利润提升。
- **输出范围：** 保留关键统计、必要来源与报告；按 `metrics/`、`provenance/`、`reports/` 分类。具体实验不默认导出逐笔预测、重复数据集或大量模型副本。
- **阶段结束：** 前五组完成后交付结果、候选及失败分支，汇报并停止。正式冻结、包括仅读4–6月的冻结参数兼容性回放、7月读取与评价均不能自动衔接。

详细公式、支持度要求、回退顺序和区间计算方法以实施方案为准，本页不重复全部实验规格。
